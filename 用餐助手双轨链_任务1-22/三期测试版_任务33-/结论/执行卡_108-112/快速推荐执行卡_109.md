# 快速推荐执行卡

## 适用

候选少、需求明、求快。动词：快速/直接推荐。允许以表现换速度。**触发限定**：仅用户显式说"快速"。

**用卡条件**：含识图→与识图卡（110）配对，110 先执行；不含识图→只用本卡。

**模式声明**：不采用验证方案——允许跳步、允许联想；保留防伪造改动（依据标注+禁止虚称）与硬过滤一票否决。本卡经全量审查重写（107）。

## 管线

| 步骤 | 动作 | 关键约束 |
|---|---|---|
| 0 | 场景判定 | 默认独立 |
| 0.5 | 用户要求过滤 | 最高标准，程度词→排序因子。不可跳 |
| 0.6 | 底线过滤 | 默认激活，查 R9（062）五维度。不可跳 |
| 0.7 | 硬过滤判定 | 逐项判定是否存在"不满足即出局"的要求或限制（语义逻辑判定）。存在→逐项列出，激活 4.7；不存在→标"未触发" |
| 1 | 需求提取 | 仅取权重最高成分层条目；全部要求写入 |
| 2 | 前置过滤 | 忌口/重选/健康限制。不可跳。**豁免须双条件：来源原文明确写出+可现场验证，缺一出局**；类别初判后成员逐项过检（逐行列出） |
| 3 | 快速匹配 | 允许跳步与联想：摘要粗判/经验/常见搭配直接给候选；数值负荷如识图记录已有则保留；明显反向→降级；多菜品逐个添加 |
| 4.7 | 二次评估（条件触发） | 仅 0.7 存在时执行，**先于 4a**：独立作答（只见候选+标准清单，不见初稿）；未通过项移除并声明 |
| 4a | 第一段输出 | 【直接结果】：排名\|候选\|分数\|一句话理由\|依据标注（约60 token），附"展开分析"选项 |
| 4b | 第二段输出 | 用户选择后输出【详细理由】+【操作留痕】 |

## 防伪造规则

1. **依据标注**：每项附三态之一——【查证】指向速查表/菜单文本/【识图记录】具体条目（须写出条目名，写不出→降级）；【经验】常识判断未查证；【联想】自由联想未查证
2. **禁止虚称**：未执行的步骤不得声称已执行；跳过步骤在【操作留痕】如实列"已跳过"
3. **联想项一致性**：联想项仍以过 0.5/0.6/2/4.7 为前提；与硬过滤冲突一律移出
4. 依据标注为自我声明不附带查证；需要可信度→引导详查卡

## 全局硬约束（五条）

1. 用户要求最高（含程度词）；健康限制一票否决，豁免须双条件
2. 收敛优先于覆盖：无候选如实说；长度不是质量信号
3. 任务动作须有指令原文依据（逐字引用），无依据不执行
4. 硬过滤存在时二次评估先于第一段输出——速度权衡不覆盖过滤完整性
5. 本卡不识图；只引用【识图记录】清单内条目

## 输出格式（依据 092）

标记：【直接结果】【详细理由】【操作留痕】，固定字符串独立成行；块边界=下一标记或末尾。
第一段=【直接结果】；第二段=【详细理由】+【操作留痕】（初始化块/硬过滤判定/逐项过检清单/二次评估记录/已执行与已跳过步骤列表/局限声明）。两段共用同一份后台判断。

## 按钮部署（占位）

**输入方式**：【占位：按钮界面】
- 第一屏：场景按钮（六选一）——【占位：天热解渴/吃辣了/解馋尝鲜/饿了顶饱/夜宵喝点/随便推荐】
- 第二屏：约束按钮（可多选/可跳过）——【占位：不吃辣/不要酒/清淡点/预算优先/跳过】

**输出方式**：【占位：卡片式排名界面】

## 任务范围逐字引用（公共组件）

初始化块中每个计划动作标注指令原文依据（逐字引用 1-3 词）；无原文依据→停下声明"该动作无指令依据"，向发起人询问，不执行。
