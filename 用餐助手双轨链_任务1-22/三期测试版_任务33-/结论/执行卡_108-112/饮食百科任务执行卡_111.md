# 饮食百科任务执行卡

## 适用

用户上传新菜品、新食谱、新搭配发现（文字/图片）。动词：记录/分析/为什么搭。**无快速模式**。

**任务目的**：理解与解释，而非推荐。以"机制是否成立"为核心。

**用卡条件**：含图片→与识图卡（110）配对，110 先执行；不含→只用本卡。

本卡经全量审查重写（107）：隔离作答改为操作性定义；经验判定锚定到具体库条目；铁律压缩。

## 与推荐卡的区别

| 项 | 推荐卡（108/109） | 百科卡（本卡） |
|---|---|---|
| 目标 | 从候选中选 | 理解用户给出的对象 |
| 输入 | 需求+候选集 | 单一对象或组合 |
| 产出 | 推荐排名 | 分析结论+经验判定 |
| 严谨度 | 允许类型级推荐 | 所有推论必须查证合理性 |

## 管线

| 步骤 | 动作 | 关键约束 |
|---|---|---|
| 0 | 对象登记 | 记录名称/构成/来源。信息不足→反问，不臆造。图片输入只引用 110【识图记录】 |
| 1 | 对象转写 | 按 R1（063）四字段标注；每个字段标支持度，"有来源"须写出指向条目（表名+条目名），写不出→降级 |
| 2 | 无支持项查证 | 无支持字段→**先查证后起草**（查证产物独立成行，先于结论写出）；查不到→标"未知"，不推断 |
| 2.5 | 推论合理性查证 | 凡机制推论（成分→效果/强度剂量/机制路径/适用范围），先查证后起草；查无依据→降级为"假设"或移除，不得作为结论 |
| 3 | 维度对照 | 逐维查表：口味（058）/营养（059）/饱腹（060）/档次（061）/底线（062）；组合对象分别转写后方向核对 |
| 4 | 机制解释 | 先查速查表；无→查原理册（017/026）；均无→声明缺口，不编造机制；推论经 2.5 查证后方可输出 |
| 5 | 经验判定 | 对照三库逐条判定：反例库（066）/组合库（084）/速查表。**判定须写明对照了哪个库的哪一条**；判定结果："可补充/不可补充+所对照条目" |
| 6 | 输出 | 对象转写/维度对照/机制解释（含查证记录）/经验判定/局限声明。结论先行 |

## 推论查证规则（步骤 2.5）

| 推论类型 | 查证要求 | 未通过处置 |
|---|---|---|
| 成分→效果 | 查权威来源（教科书/论文/官方机构） | 降级为"假设"，附未查证声明 |
| 强度/剂量 | 查具体数值或对比数据 | 标"强度未查证" |
| 机制路径 | 查机制是否被证实 | 标"机制未证实"，仅作推测 |
| 适用范围 | 查边界条件研究 | 标"适用范围未查证" |

查证产物先于结论写出（分行），引用须可回指到上下文内条目；凭记忆补写的引文=未查证。禁止用"可能/也许"包装未查证推论。

## 经验入库规则

| 判定 | 处置 |
|---|---|
| 推翻既有预设 | 写反例案例库新条目，执行卡不动 |
| 新组合可复用 | 写组合案例库新条目 |
| 新负荷/新方向 | 声明缺口，向发起人申请扩充速查表，不自行改表 |
| 无新增 | 记录"无新增经验"，不入库 |

## 全局硬约束（三条）

1. 无快速模式；对象信息不足→反问，不臆造
2. 所有推论先查证后起草；查无依据→降级或移除，不作结论
3. 用户健康信息仅当轮使用，不写入黑板
