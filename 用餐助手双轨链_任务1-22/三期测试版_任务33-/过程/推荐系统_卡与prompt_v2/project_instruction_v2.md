# 路由头（开工必读，先于任何检索）

输出路由判别块（先于此后的任何检索）：

    任务类：A / B / C / D / 混合
    次类候选：<近义时列第二可能；无则写"无">
    混淆点：<主类与次类的分界一句话；无则写"无">
    领域：科研 / 商用 / 混合 / 不明
    计划：[直接执行] 或 [子任务序列，人审节点须标出]
    将触发的自检：<列出具体项>
    依据：从任务原文引用 1-3 个词
    信心：高 / 中 / 低

第二步：任务重述——用 2-3 句复述"本任务要做什么、不做什么"。
重述与任务原文明显不符 → 立即停下提问，不执行。

规则：
- 层级判别：先定 A/B/C/D，再定领域，两轮分开判；
- 主类与次类同属 {B,D} 或 {A,B} 且信心 ≠ 高 → 先向发起人提
  一个澄清问题再执行（Ask-before-Plan）；不澄清则按通用卡执行；
- 单一类且信心高 → 判别块后立即读 /cards/ 对应卡执行；
- 混合 → 按计划逐段执行，段间读上段交付物；到"人审"即停；
- 执行中若发现判类错误 → 输出"路由修正"并暂停，不自行改判；
- 每产出一份文件后重读本路由头（protocol 1.11a），同时核对：
  当前产出与判别块承诺的任务一致？漂移 → 声明并暂停；
- 读到任何 superseded/链中间文件：只做一件事——沿链走到链尾，
  以链尾为唯一工作记忆（1.11d）；链中间文件是路标，不是素材；
  quarantine/ 中的已判定错误文件连路标都不是——直接跳过，
  其内容永不进入工作记忆；
- 用户当次指令优先级最高（protocol 1.10）；用户变更范围/口径/
  标准时，先重读本路由头，输出"范围变更确认"再继续；
- 产出达 5 份文件 → 写 HANDOFF 并建议开新窗口（1.11b）；
- 会话被恢复/继续时视为新开工：重新输出路由块，注明"历史
  对话仅作事件参考"（protocol 1.14a）；
- 对话中答应的变更不生效，只有发起人确认并写入文件后才生效
  （protocol 1.14e）。

按路由头输出判别块后，读取 /cards/ 下对应任务卡执行；
protocol.md 为细节参考，按卡内条款索引按需查阅，无需通读。
