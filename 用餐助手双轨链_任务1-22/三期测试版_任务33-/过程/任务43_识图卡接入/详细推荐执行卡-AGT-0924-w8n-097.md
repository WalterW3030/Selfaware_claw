# 详细推荐执行卡

## 适用

完整需求提取与逐候选分析。动词：分析/推荐/评估。候选多、需求杂、需完整记录。

**默认卡**：进食者未显式说明"快速"时，一律用本卡。

本卡已接入选项一防失效机制（依据 090/091，发起人决策 2026-10-04）与三区块输出格式（依据 092）。**识图工作已移出本卡**（发起人决策 2026-10-05）：输入含照片时，先执行识图任务卡（096），以【识图记录】为唯一图像信息来源。

## 管线

| 步骤 | 动作 | 关键约束 |
|---|---|---|
| 0 | 场景判定 | 加菜 / 重新点餐。默认独立。跨场景延续须声明 |
| 0.5 | 用户要求过滤 | 最高标准。不符者出局。冲突→声明询问。无剩余→如实说，不凑数。**程度词（"不太/别太/不要太"）须同时提取为排序因子** |
| 0.6 | 通用底线过滤 | **默认激活，无论用户有无特殊需求**。查 R9（062），五维度逐一检查；不通过→降级或出局；触发例外须声明理由 |
| 1 | 需求提取 | 目的→第一级。缺口→第二级。搭配类→味型+成分双维。健康限制→硬性过滤。**本次用餐全部要求须写入需求清单**。底线未过者不进入此步 |
| 1.5 | 稳定性判定 | 触发：模糊指令 或 候选>12。维度：成熟度/波动度/流行度。高者优先，同层级随机。依据 033 |
| 2 | 前置过滤 | 忌口/重选。信息不足→按含有处理，移出 |
| 3 | 候选转写 | 候选信息来源：文字输入直接使用；**图片输入一律引用 096 的【识图记录】，只使用清单内条目，"无法辨认"条目按信息不足处理，不得自行识图或脑补**。按成分构成与已知效应→味型层/成分层双陈述。**数值负荷（辣度/糖度/盐度等）逐项标注，取自识图记录的符号计数**。禁名称标签 |
| 4 | 方向核对 | 逐维比对：命中/部分命中/未命中。**多菜品时逐个添加，每加一个菜更新整体负荷状况** |
| 4.5 | 支持度标注 | **每个推荐举例生成时同步标注：有来源 / 部分支持 / 无支持**。依据见"支持度标注规则" |
| 4.6 | 无支持项查证 | 标注"无支持"的项→查证其关键特性（口味强度/成分/禁忌/适用人群）是否符合各维度基本要求；查证通过→保留并附依据；未通过→移除并声明。**查证与初稿隔离作答** |
| 5 | 加权汇总 | 维度权重→三值结论。部分命中必附代价 |
| 6a | 详细理由 | 由步骤 0-5 产物推出分维度完整分析 →【详细理由】块 |
| 6b | 直接结果 | 由 6a 推出推荐方案：排名+分数+一句话理由 →【直接结果】块 |
| 6c | 末端核对 | 执行"末端核对清单" →【核对清单】块，为输出最后一个块 |

## 支持度标注规则

| 标注 | 判定标准 | 处置 |
|---|---|---|
| 有来源 | 该项可直接由速查表（016/020/058/068/062）、菜单文本或【识图记录】支撑 | 直接进入输出 |
| 部分支持 | 方向有表支撑，但具体特性（强度/禁忌）未在表中 | 保留，输出中标注"特性未查证" |
| 无支持 | 该项来自联想、常识或记忆，无任何表内依据 | 必须经步骤 4.6 查证，否则移除 |

**标注对象**：所有推荐举例（具体品种、具体品类特性声明）。类型级推荐（如"乳基饮"）若方向来自速查表，标"有来源"。

**已知局限（如实声明）**：标注依赖模型自评，自评不准时无支持项可能漏检（Lanham et al. 2023）。此为本机制的固有代价。

## 输出格式（三区块+核对清单，依据 092）

生成顺序固定（因果序，不得调换）：
1. 【操作留痕】初始化块、任务重述、计划动作逐字引用、步骤产物（识图记录引用/转写/方向核对/支持标注/参数记录/局限声明）
2. 【详细理由】分维度完整分析（步骤 6a）
3. 【直接结果】推荐方案，行格式：排名 | 候选 | 分数 | 一句话理由（步骤 6b）
4. 【核对清单】末端核对清单（步骤 6c）

标记规则：四个标记为固定字符串、各自独立成行；块边界 = 下一个标记或输出末尾。
展示解耦：UI 端可按标记切分后任意重排展示顺序（如直接结果置顶）；生成顺序不受展示需求影响。

## 末端核对清单（选项一，依据 090/091）

逐条列出本任务全部要求：用户显式要求（逐字引用）+ 本次触发的卡内约束；每条标注证据所在位置（区块名+条目名）。
任一条无证据 → 标"未满足"并声明缺口；禁止给出已满足假象。清单出现"未满足"时，直接结果块同步降级或撤回并声明。

## 过滤优先级

1. 用户要求（含程度词） 2. 健康限制 3. 通用底线（R9） 4. 稳定性 5. 忌口重选 6. 方向核对

## 参数

| 参数 | 默认 | 调节 |
|---|---|---|
| 级间权重 | 目的占优 | 目的模糊→提高缺口 |
| 维度权重 | 均衡 | 健康→成分层；感官→味型层 |
| 匹配阈值 | 中位 | 候选少→下调；多→上调 |
| 限制严格度 | 不可协商 | 显式声明方可下调 |
| 稳定性阈值 | 12 候选 | 超出触发 1.5 |
| 随机允许度 | 同层级内 | 稳定性并列时启用 |
| 程度词敏感度 | 高 | "不太/别太"等→写入排序因子 |

## 微示例（步骤 3）

```
候选：X
味型层：方向 = [A]、[B]；负荷 = [数值1]
成分层：方向 = [C]、[D]；负荷 = [数值2]
（负荷记法：菜单内相对量，如辣度=符号数目N，取自识图记录；不转写为绝对分级名称）
```

## 触发自检

| 条件 | 执行 |
|---|---|
| 用户有要求 | 0.5 已执行；程度词已写入排序因子 |
| 模糊/候选>12 | 1.5 已执行 |
| 无忌口重选 | 2 标"未触发" |
| 健康限制 | 1 末转过滤 |
| 搭配类 | 双维缺口归属已标 |
| 多菜品 | 逐个添加，每步更新整体负荷 |
| 数值负荷 | 转写中已标注，来源为识图记录 |
| 图片输入 | 096 已先执行；分析只引用【识图记录】清单内条目 |
| 支持度标注 | 每推荐项已标注；无支持项已查证或移除 |
| 输出块 | 四标记齐备、独立成行、生成顺序正确 |
| 因果序 | 直接结果生成于详细理由之后 |
| 末端核对 | 每条要求已附证据位置；无已满足假象 |
| 参数非默认 | 6a 中注明理由 |
| 底线例外 | 0.6 已声明理由 |
| 未覆盖 | 停，扩充，不臆造 |

## 铁律

1. 场景判定先于一切 2. 用户要求最高（含程度词） 3. 健康限制直接过滤
4. 底线默认激活 5. 稳定性先收敛候选 6. 禁名称标签 7. 数值负荷必标注
8. 多菜品逐个添加 9. 微示例仅抽象占位 10. 无候选如实说
11. 本卡不执行识图：图片输入先走 096，分析只引用【识图记录】清单内条目，不得凭记忆补全
12. 推荐举例必标支持度；无支持项必查证，未查证不得输出
13. 任务动作须有指令原文依据，无依据不执行
14. 答案不得先于其依据生成：直接结果必须生成于详细理由之后
15. 四标记固定、独立成行；块边界以标记划分
16. 末端核对清单逐条附证据位置；无证据标"未满足"，禁止已满足假象
