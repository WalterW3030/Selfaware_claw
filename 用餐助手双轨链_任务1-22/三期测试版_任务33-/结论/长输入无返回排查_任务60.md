## 一、无返回全分支清单（4条主路径 + 2条面板/平台层）

### 分支A：云函数执行超时被平台终止【最可能】

- 代码锚：`index.js:191` `res = await dispatch(cfg, msgs)` → `callExtend` `index.js:61` `await client.generateText(data)`。调用层无任何超时控制；`data={model,messages}`（`index.js:60`）未设 max_tokens，输出长度不受限。
- 机理：长输入 → 模型生成长输出 → 执行时间超过云函数【超时配置】→ CloudBase 终止实例。官方依据：CloudBase FAQ"云函数执行超时……超时客户端会直接断开连接并报错""在云控制台调整为需要的超时时间（上限为60s）"；微信错误码 `-604102` 调用超时。
- 关键疑点【事实】：部署台账只记录过 importRefTables 在云端配过 timeout=60s；aiGateway 云端超时时间从未配置过，当前值未知。若为默认值（社区实证默认 3s/20s 两档，见检索留痕），"你好"短输出可在时限内完成，长句生成（社区实证 DeepSeek 响应 5-10s 起）直接超限。
- 云端日志鉴别特征：控制台→云函数→aiGateway→日志中，长句那次调用有记录，执行时长≈超时配置值后被终止，无"返回"记录或标记超时/TimeLimitReached。
- 可能性：高。"你好能答、长句无结果"与该分支完全同构。

### 分支B：上游 promise 不 settle（extend 平台挂起）

- 代码锚：同分支A的 `index.js:61`。extend 平台侧挂起（内部排队/网络）时 `generateText` 的 promise 永不 resolve/reject，函数干等到超时被终止。
- 与A的区别仅在上游，代码层不可分；处置相同（超时配置+日志鉴别）。
- 云端日志鉴别特征：同A——时长≈超时值终止；函数日志内无任何模型响应到达痕迹。

### 分支C：generateText resolve 假值 → 网关原样透传空【代码可确认存在的无声路径】

- 代码锚：`index.js:191` res 收值后——
  - `index.js:196` `if (res && res.error)`：res 为 undefined/null/'' 时跳过；
  - `index.js:198-208` nutrition 数字闸仅 mode==='nutrition' 生效，chat 位不拦；
  - `index.js:218` `computeHealthNotice(mode, extractText(res))`：extractText(null)→null（`index.js:118`），返回 false；
  - `index.js:220` `if (res && typeof res === 'object' && !Array.isArray(res))`：对 undefined/null/'' 均不成立；
  - `index.js:223` `return res`：原样返回 undefined/空串。
- 机理：云测试面板收到"执行成功但返回体为空"→ 显示空白、无报错。这是全代码中唯一"函数成功执行但调用方什么都看不到"的出口。
- 云端日志鉴别特征：该次调用日志显示正常完成（有返回日志、无异常、无超时终止），但返回体为空。
- 可能性：中。取决于 extend SDK 在何种边缘下 resolve 假值（如上游 200 空包/内容过滤后空 choices）。

### 分支D：回包超 1MB 被微信平台截断

- 代码锚：`index.js:223` return res 透传完整模型输出，无大小护栏。
- 机理：微信云函数回包上限 1M（错误码 `-604001` 回包大小超过1M）。长输入诱导超长输出时函数执行成功、平台在回包阶段截断。
- 云端日志鉴别特征：函数日志=执行成功有返回；客户端侧/平台侧报 `-604001`。需模型输出约 50 万汉字才触发，单句长输入不现实。
- 可能性：低。列出仅为完备。

### 分支E：云测试面板入参层（非网关代码）

- 长句含未转义引号/换行 → JSON 非法，面板层报错（与"无报错"矛盾，基本可排除）；或个别面板存在输入长度限制。
- 鉴别：换一条不含特殊字符的长句重试即知。

### 分支F：同步调用日志 4k 显示上限（CloudBase FAQ）

- 官方FAQ："云函数测试时，如果以同步调用的方式（超时时间小于20秒），返回的日志最多为4k，超过4k的日志不显示"。若长句响应体超4k，测试面板可能呈现不完整。鉴别：面板显示"部分结果"而非"完全无结果"时可疑。

## 五、结论（事实/推断分层）

【事实】
1. 代码层唯一"成功执行但空显示"出口为分支C（index.js:196-223 假值透传链）。
2. 其余无声路径（A/B/D）均为平台层终止/截断，函数日志可鉴别。
3. aiGateway 云端超时时间当前值无记录，是最大未知项。

【推断】
1. 按"你好能答、长句无结果"同构性，分支A（超时配置未调或不足）概率最高；分支C次之。
2. 二者判别只需一条云端日志（执行时长+终止记录）。
