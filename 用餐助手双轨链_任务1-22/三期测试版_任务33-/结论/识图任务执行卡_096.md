# 识图任务执行卡（照片信息识别与记录）

## 适用

输入含照片（菜单/菜品/店面/价目表等）时的独立前置任务。动词：识别/转录/记录。
本卡只做识别与记录，不做推荐、不做分析结论。推荐任务（093/094）不自行识图，一律消费本卡产物。

## 任务性质声明

目的：把照片内的信息**完整、正确**地转为可查对的文字记录。识图不全与混淆文字是失效重灾区（090），故本卡以"全量转录"为第一优先，速度让位。

## 管线

| 步骤 | 动作 | 关键约束 |
|---|---|---|
| 0 | 图像清点 | 列出本次输入的图片数量与各自主题（菜单/菜品/其他）；多图分别编号 |
| 1 | 分区全量转录 | 每张图按从左到右、从上到下分区扫描，**将全部文字与物品逐项转录为清单**：菜名、价格、符号、图例、说明文字、装饰文字均计入，不得遗漏、不得跳项、不得凭记忆补全 |
| 2 | 标注体系判定 | 在转录清单内找图例/说明文字，判定辣度/推荐度等符号的标注体系；清单内无图例→如实声明"无图例"，不得假设 |
| 3 | 逐项符号计数 | 对照菜品旁符号逐项计数并写入清单条目；计数与菜名一一对应 |
| 4 | 不确定标注 | 模糊/遮挡/无法辨认的条目→标"无法辨认"并描述位置，**禁止猜测填充** |
| 5 | 输出记录 | 见下方输出格式 |

## 输出格式

【识图记录】
- 图N：<主题>
  - 分区转录清单（逐条：位置 | 文字/物品 | 符号计数 | 置信：清晰/模糊/无法辨认）
  - 标注体系判定：<体系描述 或 "无图例">
  - 遗漏声明：<已确认无遗漏 或 列出未能覆盖区域>

## 与推荐任务的接口

- 推荐任务收到图片时：先执行本卡，将【识图记录】作为唯一图像信息来源；
- 推荐任务的分析只引用清单内条目，清单外内容一律不得使用；
- 清单内"无法辨认"条目：推荐任务按信息不足处理（忌口场景按含有处理），不得自行脑补。

## 辣度符号口径（与推荐卡一致）

菜单有图例或自有分级体系时以菜单为准；无图例时按符号数目在菜单内排序相对辣度，不对应微辣/中辣等绝对名称，不跨菜单比较；标注体系惯例查 051。

## 触发自检

| 条件 | 执行 |
|---|---|
| 每张图 | 分区转录清单已输出，含位置与置信 |
| 无法辨认 | 已标注并描述位置，未猜测填充 |
| 图例 | 已判定或如实声明"无图例" |
| 符号计数 | 逐项与菜名对应 |
| 遗漏声明 | 已输出 |

## 铁律

1. 全量转录先于一切分析 2. 只转录图中实际存在的内容，不得凭记忆/常识补全
3. 无法辨认如实标注，禁止猜测填充 4. 本卡不产出推荐与搭配结论
5. 辣度以菜单自有体系为准，无图例仅按数目排相对序，不绝对化、不跨菜单
