# Walter 操作详细指南：食知测试版环境搭建与联调

版本：v1.0 | 2026-09-23 | 编制：kimi
用途：手把手完成测试版的全部人工操作。按顺序做，每步有"做完标志"。遇到问题先查文末"常见问题"，解决不了把报错截图发我。

---

## 第1步：安装微信开发者工具（约10分钟）

1. 打开 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载 **Nightly 版**（页面里找"Nightly Build"，选 Windows 或 macOS 对应版本）。Nightly 内置更新的 AI 能力和 CodeBuddy 支持。
3. 安装并用你的微信扫码登录。

做完标志：能打开工具、看到"导入项目"界面。

## 第2步：注册个人主体小程序（当天可完成）

1. 浏览器打开 https://mp.weixin.qq.com/ ，点"立即注册"。
2. 账号类型选**小程序**；主体类型选**个人**，按提示填身份证+手机号+扫脸。
3. 注册完成后进后台，左侧菜单 **开发 → 开发管理 → 开发设置**，记下两样：
   - **AppID**（形如 wxxxxxxxxxxxxxxx）
   - AppSecret（暂时用不到，不用发给我）
4. 不需要认证、不需要类目、不需要执照——开发测试阶段这些都不碰。

做完标志：拿到 AppID。
备选：如果注册卡住，可先在开发者工具里用**测试号**导入工程（导入时选"测试号"），AppID 后补。

## 第3步：开通云开发并填环境ID（约5分钟）

1. 打开微信开发者工具 → 导入项目 → 目录选仓库里 `三期测试版_任务33-/过程/任务34_原生工程与网关/`（注意：选这个原生工程目录，不是任务33的旧骨架目录）。
2. AppID 填第2步拿到的（或选测试号）。
3. 导入后，工具顶部工具栏点 **"云开发"** 按钮 → 开通 → 环境名称随便起（如 `shizhi-test`）。
4. 开通后在云开发控制台右上角 **设置（齿轮）→ 环境设置**，复制**环境ID**（形如 `shizhi-test-xxxxxx`）。
5. 用编辑器打开工程里的 `app.js`，找到：
   ```javascript
   wx.cloud.init({
     // ENV_ID：Walter 填写
     env: '',
   ```
   把环境ID填进引号里，保存。

做完标志：app.js 的 env 已填，工具左下角不再报"云开发未初始化"。

## 第4步：控制台核查在售模型（P7项，2分钟）

1. 云开发控制台 → 左侧找 **AI+ / AI 能力 / 模型** 相关入口（不同版本叫法略不同，找"模型"字样）。
2. 看在售模型列表，**截图发我**。我要确认的是：列表里哪个模型支持**图片输入**（重点是 deepseek-flash 是否开了多模态）。
3. 如果列表里根本没有 AI/模型入口，也截图发我（说明该环境未开放，识图位按备选方案走自备API）。

做完标志：截图发到群里。

## 第5步：部署 aiGateway 云函数并联调（约15分钟）

1. 开发者工具左侧文件树展开 `cloudfunctions/aiGateway/`。
2. **右键 `aiGateway` 文件夹 → "上传并部署：云端安装依赖"**。等部署完成提示。
   （备选路径：如果你装了 CodeBuddy 扩展，可以直接对它说"部署 aiGateway 云函数"。）
3. 右键 `aiGateway` → **"本地调试"**（或云开发控制台 → 云函数 → aiGateway → 云端测试）。
4. 测试参数（event）粘贴这段：
   ```json
   {
     "mode": "chat",
     "messages": [{"role": "user", "content": "用一句话介绍你自己"}]
   }
   ```
5. 点运行，把**返回内容截图或复制发我**。

做完标志：返回里有模型真实回答的文本。
- 如果报错，对照 `网关部署与联调说明.md` 的报错对照表（环境ID未配/基库过低/模型未开通），对不上的把完整报错发我。

## 第6步（可选）：自备API备选通道（约10分钟）

1. 去百炼（阿里云）或智谱开放平台注册，创建一个 API key。
2. 开发者工具 → 云开发控制台 → 云函数 → aiGateway → **配置 → 环境变量**，加两条：
   - `SELFHOST_BASE_URL` = 服务商的 OpenAI 兼容地址（如百炼 `https://dashscope.aliyuncs.com/compatible-mode/v1`）
   - `SELFHOST_API_KEY` = 你的 key
3. **key 不要发到群里**，只配在环境变量里。
4. 这一步不影响主线，什么时候办都行。

## 第7步（可选）：添加微信同声传译插件（5分钟）

1. mp.weixin.qq.com 小程序后台 → 左侧 **设置 → 第三方设置 → 插件管理** → 添加插件。
2. 搜索 **"微信同声传译"**（AppID：wx069ba97219f66d99），申请添加（官方插件，个人主体可过）。
3. 工程 app.json 里已经写好声明（版本0.3.5），后台加完即可用。

做完标志：插件管理里显示"已添加"。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 导入工程后红字报"cloud is not defined"类 | 基库版本低：工具右上角 详情 → 本地设置 → 调试基础库选 3.15.1 以上 |
| 云函数部署按钮灰色 | 云开发未开通或 env 未填，回第3步 |
| 测试返回 `unknown mode` | event 里 mode 拼写，必须是六+二位之一（recognize/copy/nutrition/order_fast/order_deep/chat/translate/order_phrase） |
| 返回 `模型未开通`类报错 | 第4步的截图发我，换在售模型 |
| 真机预览白屏 | 详情 → 本地设置 → 勾"不校验合法域名…"（仅开发期） |

## 回报格式

每办完一步在群里说一句"第N步完成+结果/截图"即可。第5步的返回内容最关键，决定T2联调验收和第三部分开工。
