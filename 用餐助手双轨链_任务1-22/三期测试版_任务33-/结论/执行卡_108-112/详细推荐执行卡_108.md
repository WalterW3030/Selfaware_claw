# 详细推荐执行卡

## 适用

完整需求提取与逐候选分析。动词：分析/推荐/评估。**默认卡**：未显式说明"快速"时一律用本卡。

**用卡条件**：含识图→与识图卡（110）配对，110 先执行；不含识图→只用本卡。

本卡经全量审查重写（107）：删除触发自检表/局限声明段/重复铁律，支持度标注锚定到条目引用，核对唯一化为末端清单。

## 管线

| 步骤 | 动作 | 关键约束 |
|---|---|---|
| 0 | 场景判定 | 加菜/重新点餐。默认独立 |
| 0.5 | 用户要求过滤 | 最高标准。不符出局；冲突→声明询问；无剩余→如实说。程度词写入排序因子 |
| 0.6 | 通用底线过滤 | 默认激活，查 R9（062）五维度；不通过→降级或出局；例外声明理由 |
| 0.7 | 硬过滤判定 | 逐项判定是否存在"不满足即出局、不可被排序折中"的要求或限制（语义逻辑判定，非关键词）。存在→逐项列出+出局后果性质，激活 4.7；不存在→标"未触发" |
| 1 | 需求提取 | 目的→第一级；缺口→第二级；搭配类→味型+成分双维；全部要求写入需求清单 |
| 1.5 | 稳定性判定 | 触发：模糊指令 或 候选>12。依据 033 |
| 2 | 前置过滤 | 忌口/重选/健康限制；信息不足→按含有处理移出。**豁免须双条件同时满足：来源原文明确写出+条件可现场验证；缺一出局** |
| 2.5 | 类别成员逐项过检 | 类别初判后每个成员单独过健康限制/硬过滤，逐行列出判定；类别只用于组织输出 |
| 3 | 候选转写 | 图片输入只引用 110【识图记录】清单内条目，"无法辨认"按信息不足处理。味型层/成分层双陈述，数值负荷逐项标注。禁名称标签 |
| 4 | 方向核对 | 逐维比对：命中/部分命中/未命中；多菜品逐个添加，每加一个更新整体负荷 |
| 4.5 | 支持度标注 | 每项标：有来源/部分支持/无支持。**"有来源"必须写出指向条目（表名+条目名）；写不出→降级为无支持** |
| 4.6 | 无支持项查证 | 无支持项→先查证后起草：查证关键特性（口味强度/成分/禁忌/适用人群），通过→保留附依据；未通过→移除并声明。**引用必须可回指到上下文内条目（速查表条目/识图记录条目/本轮查证记录），指向记忆的引用=无支持** |
| 4.7 | 二次评估（条件触发） | 仅 0.7 判定存在时执行。独立作答：只输入候选清单+硬过滤标准清单，不输入初稿结论；逐项判定后与初稿比对；未通过项移除并声明，误判出局项恢复并声明 |
| 5 | 加权汇总 | 维度权重→三值结论；部分命中必附代价 |
| 6a | 详细理由 | 由 0-5 产物推出 →【详细理由】 |
| 6b | 直接结果 | 由 6a 推出：排名\|候选\|分数\|一句话理由 →【直接结果】 |
| 6c | 末端核对 | →【核对清单】，输出最后一个块 |

## 全局硬约束（五条）

1. 用户要求最高（含程度词）；健康限制一票否决，豁免须双条件
2. 收敛优先于覆盖：无候选如实说，清单短如实说；长度不是质量信号
3. 任务动作须有指令原文依据（逐字引用），无依据不执行
4. 答案不得先于其依据生成：直接结果在详细理由之后
5. 本卡不识图；分析只引用【识图记录】清单内条目

## 输出格式（依据 092）

生成顺序固定：【操作留痕】（初始化块/重述/逐字引用/步骤产物）→【详细理由】→【直接结果】→【核对清单】。
标记为固定字符串、独立成行；块边界=下一个标记或输出末尾；UI 可切分重排，生成顺序不变。

## 末端核对清单

逐条列出本任务全部要求（用户显式要求逐字引用+触发约束，含 0.7/2.5/4.5/4.6/4.7 是否执行及结果），每条附证据位置（区块名+条目名）。无证据→标"未满足"并声明；禁止已满足假象；出现"未满足"→直接结果降级或撤回并声明。

## 参数

| 参数 | 默认 | 调节 |
|---|---|---|
| 级间权重 | 目的占优 | 目的模糊→提高缺口 |
| 维度权重 | 均衡 | 健康→成分层；感官→味型层 |
| 匹配阈值 | 中位 | 候选少→下调；多→上调 |
| 限制严格度 | 不可协商 | 显式声明方可下调 |
| 稳定性阈值 | 12 候选 | 超出触发 1.5 |
| 程度词敏感度 | 高 | "不太/别太"→排序因子 |

## 微示例（步骤 3）

```
候选：X
味型层：方向=[A]、[B]；负荷=[数值1]
成分层：方向=[C]、[D]；负荷=[数值2]
（负荷记法：菜单内相对量，取自识图记录符号计数；不转写为绝对分级名称）
```
