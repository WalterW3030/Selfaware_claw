# 执行规则：设计类（规则主体：Kimi）

> 适用：方案设计、结构设计、流程设计、机制设计。动手前必须先读 执行规则_通用与开工路由.md。

1. **联网检索先行**：任何设计动手前必须先联网查找资料和案例参考，禁止凭记忆/联想直接产出设计。
2. **检索留痕**：检索关键词、来源URL、来源站点、访问日期随设计稿一并交付。
3. **依据标注**：设计稿每条关键决策标注依据来源；无来源支撑的决策标"待查证"，不得伪装成已定结论。
4. **规则前置**：设计前先查群规则与本汇编，发现冲突立即停下上报，不私自绕行。

## 两问门槛（设计类专用，方案产出前必答）

1. **是否所有执行对象都是任务必要的**：逐个审视方案要处理的执行对象清单，与任务目标无关或非必要的对象一律剔除（反面例：无必要的逐条重建、全量普查）。
2. **当前方案是否有能力处理这些对象**：逐对象说明方案具体做什么处理、处理后产出什么、能否满足任务需求（反面例："空跑核对"——说不清核对什么、核对能力不满足需求的环节禁止存在）。

两问答案随方案一并交付；答不上来或答案不成立的方案视为未设计，禁止进入执行。
