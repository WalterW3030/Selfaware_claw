# 前置过滤预筛选的加速方案可免全量转写

约束（来自发起人任务原文与确认）：
- C1 忌口选项：筛选之前，将所有可能包含忌口内容的候选移出备选单。
- C2 重选选项：将所有已选过的候选移出备选单。
- C3 快速方案：保留忌口与重选功能的前提下，允许以影响表现为代价换取筛选速度。
- C4 加速效果为估测，须显式标注推断属性。
- C5 沿用 [[AGT-0924-w8n-003]] 的禁令：禁止举例、禁止罗列关键词、不绑定特定菜品。

## 一、两个新增选项的定位与接入

两者均接入 [[AGT-0924-w8n-003]] 候选匹配的第 3 步（硬性过滤）之前，作为**第 0 步前置过滤**，一次遍历完成，被移出者不参与后续任何环节。

- 忌口：候选按其完整成分构成核对，凡成分中含忌口项、成分来源无法排除忌口项、或成分信息不足以做出排除判断的，一律移出。信息不足按含有处理，与限制严格度参数的默认方向一致；进食者显式下调限制严格度时，仅"成分来源可排除"者放行，"信息不足"者仍移出。
- 重选：以本次任务的匹配结果记录为已选清单，凡在清单内的候选一律移出；进食者声明跨任务延续时，清单范围按声明扩大，并须记录所声明的范围。

两者过滤后的剩余集合称为备选单，进入既有的转写、核对、汇总环节，流程不变。

## 二、快速方案：预筛选 + 惰性转写 + 维度下推

在完整模型上做三处改动，忌口与重选功能原样保留：

1. 属性预筛选：为每个候选预先整理一份成分与效应摘要（首次整理，此后复用）；执行时先按需求清单中权重最高的成分层条目对摘要做粗判，明显反向者直接降级为不匹配，不再生成味型层陈述，也不再进入方向核对。摘要成分信息不足以支撑粗判的候选，不得凭摘要降级，转入完整转写。
2. 惰性转写：方向核对所需的候选转写只在候选进入核对时才生成，被前置过滤与粗判降级者不产生转写成本。
3. 维度下推：对粗判存疑的候选先做成分层核对，成分层未命中且其维度权重不低于味型层时，直接定为不匹配，跳过味型层核对；味型层权重大于成分层时执行顺序对调。仅当高权重维度命中时才核对低权重维度。

功能保留性：忌口与重选在第 0 步执行且先于一切降级判定，故任何加速改动不影响两者的过滤结果——被忌口或重选规则排除的候选，在快速方案中与完整方案中完全一致地被排除。

表现代价的来源：粗判可能将"成分层方向表面相反、但经完整转写后实为部分命中"的候选提前降级；维度下推可能漏掉"高权重维度未命中、低权重维度命中"本应判为部分匹配的候选。两类代价均随匹配阈值与维度权重的取值变化，参数记录中须注明本次执行启用了加速路径。

## 三、加速效果估测（推断，非实测）

估测口径：以候选平均处理成本为单位，比较完整方案与快速方案的单候选成本；以下为基于流程结构的推断，未经实测。

- 完整方案：每个候选均经双维转写与双维核对，单候选成本记为 1。
- 快速方案：摘要粗判约耗费完整转写成本的一至两成；假定三到五成候选在粗判或维度下推阶段终止，则通过者承担约五至七成的完整成本，被终止者承担约一至三成。整体单候选成本估为完整方案的四到六成，即筛选速度估为约 1.7 至 2.5 倍。
- 规模效应：备选单越大，被终止候选的绝对数量越多，加速比越高；前置过滤缩小备选单本身也直接减少总工作量，但该收益与加速路径无关，不计入上述倍数。

此估测最可能因以下因素失效：候选的成分信息完整度（信息越全，粗判终止率越高、加速越明显）；需求清单的成分层条目数量（条目越多，粗判通过率越高、加速越弱）；维度权重的实际取值（两级权重差距越小，维度下推的终止率越低）。

## 四、产出形式（在既有四部分基础上追加）

快速方案执行的产出在 [[AGT-0924-w8n-003]] 第五节的四部分之外，追加两项：前置过滤记录（被忌口、重选移出的数量与规则版本，不记候选名以符合无举例约束）与加速声明（本次启用的加速路径、粗判与下推的终止数量、估测依据）。参数记录中"匹配阈值、维度权重、限制严格度"三项取值照旧必填。

## 与既有方案的关系

本文件是 [[AGT-0924-w8n-003]] 匹配环节的扩展与加速变体，未改动其需求提取结构；忌口与重选两个选项为新增功能，此前各方案均未包含。
